# Windows 办公室部署

## 环境与入口

Windows 10/11 x64、可写磁盘、同一可信办公室局域网。API 模式只需要服务器能访问模型服务，不使用 GPU。浏览器使用现代 Edge/Chrome。发行 ZIP 自带 Python、Pillow 和 PDFium；源码启动需要 Python 3.14 x64，并在 `.venv` 安装 `requirements.txt`。

`Launch.cmd` 是仅监听 127.0.0.1 的单机入口，资料放 `Data`。`StartServer.cmd` 是共享办公室入口，资料放 `ServerData`，读取 `ServerConfig.json`。同事使用浏览器访问服务器，不在各自机器运行单机入口。

## 首次安装

1. 下载仓库稳定 Release 的 ZIP 和 `.sha256`。使用 `Get-FileHash -Algorithm SHA256 <文件>` 对比；完整解压到固定可写目录，不在压缩包内直接运行。
2. 运行 `StartServer.cmd`，首次配置会列出私有 IPv4，选择真实办公室网卡。默认端口 8765；避免 VPN、Docker 和虚拟网卡。路由器做 DHCP 地址保留可避免链接变动。
3. 浏览器在服务器本机打开 `http://127.0.0.1:8765/`，使用启动控制台显示的初始化码创建首个管理员。密码由本人输入；初始化完成后员工才能注册。
4. 管理员在服务器本机配置 API：Base URL 通常以 `/v1` 结尾，模型必须支持图片。Key 不放入配置文件或命令。默认仅进程内保存；勾选记住则使用当前 Windows 用户 DPAPI。HTTP 下不允许远程页面改 API，远程桌面可打开服务器本机浏览器完成。
5. 需要其他电脑访问时运行 `EnableLan.cmd`，确认 Windows 提权。规则仅对当前 Python 路径/端口、Private/Domain、LocalSubnet 生效。网络应由管理员设置为真实可信的办公室配置；不要关闭防火墙或添加 Public 规则。
6. 在另一台办公室电脑打开 `http://<服务器IP>:8765/`，自行注册用户名、密码、职位。无验证码、邀请码或管理员审批；设计无法注册为管理员。由另一台电脑实际登录后才算跨机器验收完成。

可用下面命令代替交互配置（便携包用 `runtime\python.exe`，源码用 `.venv\Scripts\python.exe`）：

```powershell
.\runtime\python.exe tools\configure_server.py --ip 192.168.1.100 --port 8765
```

该命令拒绝覆盖既有配置。更改地址前备份文件；`allowed_hosts` 必须明确列出所用 IP/主机名及端口，保留 localhost 和 127.0.0.1，不用通配符。监听 `0.0.0.0` 并不表示公网部署受支持。

## 日常使用与停止

长期项目保存 Guide、LOGO 和共用规范；每次活动创建独立稿件填写文案/需求。已配置 API 时上传 Guide 会自动发起解析，按服务商计费；可先用虚构 Samples 验收。设计选择项目与稿件上传成稿，报告由人工确认。

所有已登录成员共享项目库，没有项目级隔离。管理员管理账号和模型服务；编导/运营维护资料；设计送审与查看报告。并发修改冲突会要求重新确认，避免静默覆盖。审核中不要关闭服务器。

用页面内“退出程序”正常关闭（办公室版需管理员），等待后台退出后再备份。重复双击同一入口会复用已运行实例。关闭或注销 Windows 会影响服务；远程桌面断开连接可保留用户会话，注销则不行。

## 登录后自动启动

需要时才运行 `InstallStartup.cmd`，为当前 Windows 用户登记 `ReviewOffice-<目录摘要>` 计划任务。它在该用户登录后启动，不是开机登录前的 Windows 服务。目录移动后需重新配置规则和任务；旧规则/任务应由管理员核对后移除，脚本不会主动删除其他安装。

## 备份、升级和回退

- 正常退出后完整备份 `ServerData`（或单机 `Data`）及 `ServerConfig.json`。SQLite 账号库、上传资产、历史快照和 workspace JSON 都要保留，不只备份一个文件。
- 新版解压到独立目录，将旧资料复制过来；若目标已有资料，分别备份后决定使用哪份，不要合并覆盖。首次启动可能创建迁移前 workspace 备份，原文案迁入独立稿件。
- DPAPI Key 绑定原 Windows 用户；换电脑或用户后需重新填写，不导出明文 Key。升级不会自动重发失败任务。
- 旧版无法保证读取新结构。回退应恢复**升级前完整备份**，不要用旧程序打开已经迁移的数据。
- 忘记密码：在服务器本机先退出程序，运行 `ResetAccount.cmd`，按提示输入账号与新密码；不需要读取原密码。

## HTTPS 与公网

如单位提供有效证书，可在 `ServerConfig.json` 设置 `tls_cert`、`tls_key` 为服务器本机证书文件路径，且证书名称须匹配访问域名。私钥不进入 Git/发行包/聊天。HTTPS 后 Cookie 带 Secure；自签名证书的企业信任分发需要另行配置，本版未做企业证书部署验收。`ConfigureServer.ps1` 遇到现有 TLS 配置会拒绝覆盖。

此应用面向可信办公室 LAN。无项目隔离、无自助邮箱验证，不适合直接开放互联网。不要做公网端口映射或临时隧道来替代局域网部署。

## 故障排查

- 启动报错：先看启动控制台、`startup-error.txt`；运行诊断见资料目录 `diagnostics.log`，不要公开上传完整日志/资料库。
- 本机可开、同事打不开：核实 IP、同一网段、端口占用、`allowed_hosts`、实际网络配置和 Python 防火墙路径；先检查 `http://127.0.0.1:<端口>/api/health`。没有第二台电脑证据时应明确标记局域网验收未完成。
- HTTP 401/403：检查 Key、端点和模型权限。HTTP 402：在服务商控制台检查该 Key 的可用余额和计费限制。
- HTTP 429：检查限流配额。HTTP 503/504：查看失败步骤、图片数/体积、耗时和 Trace ID；可能是服务商或网关暂时不可用，不能仅凭状态确定根因。可按服务商文档检查流式选项，但不保证解决过载。
- 不自动重试、不自动换模型。超时/断流可能已被服务商受理，实际计费状态需在控制台核实后再手动决定。
- 测试连接仅读模型列表；真实审核仍可能因余额、图片能力或输出格式失败。缺失 Token 用量显示未知。

## 源码与验收

源码启动命令见 README。离线测试不发起收费 API，产物在 `TestResults`；便携包可运行 `runtime\python.exe -m unittest discover -s tests -v`。发布验收记录范围见 `docs/RELEASE_VALIDATION.md`。真实模型质量、实际服务器网卡、防火墙和登录任务应在目标环境逐项验证。
