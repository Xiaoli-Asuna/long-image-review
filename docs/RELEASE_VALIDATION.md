# v1.0.0 发行验证范围

发行前执行 Windows x64 离线单元/集成测试，使用虚构 Guide、文案、图片以及本机固定 HTTP/SSE 服务；验证便携入口实际启动、三个职位自助注册、重复启动复用、重启持久化、会话撤销、正常退出及旧版虚构资料升级。对发行包校验逐文件 SHA-256、ZIP 完整性和隐私排除规则。

具体发布结果以对应 GitHub Release 的说明和 CI 记录为准。测试不会使用真实客户素材、真实 Key 或收费模型，不能证明模型准确率。免安装启动检查使用回环地址，不能代替另一台办公室电脑访问的验收；目标服务器防火墙、登录任务、证书和真实模型需部署时另行验证。浏览器文件上传、导出交互和人工终审应由使用者实际试用。
