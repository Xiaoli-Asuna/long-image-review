# 数据与隐私

上传文件、项目、稿件、历史报告、调用记录保存在运行机器的 `Data` 或办公室服务器的 `ServerData`。本项目没有自带云端资料库或遥测服务；配置的模型服务和其隐私政策由部署者选择。

API 设置有效时，上传或重新解析 Guide 会发送该资料的文字/页面图片给模型服务；设计审核会发送所选稿件的必要文案、已确认规范及参考/设计切片。其他稿件和未选 Excel 备注不作为本次审核输入。接口请求包含服务所需的认证 Key。实际数据保存策略、地域与收费以所选服务合同为准，使用客户材料前由部署者确认授权。

Key 默认仅存进程内，重启需重新填写；选择记住时保存在当前 Windows 用户 DPAPI 加密文件。账号密码使用带盐 PBKDF2 摘要；账号库不属于可公开资料。办公室默认 HTTP，不提供传输加密，须在可信网络使用；有机密传输要求时部署有效 HTTPS 后再使用。

调用记录保留状态、可用的安全错误码/追踪编号、用量与诊断摘要，不回显原始服务错误正文或 Key；报告仍可能包含文案、图片和业务事实，导出 HTML 不是脱敏操作。用户上传的文件名也可能敏感。

所有登录成员共享项目资料。关闭程序后完整备份资料目录，限制 Windows 文件访问权限；删除或转移时同时考虑备份、导出报告和服务商侧留存。不要把真实工作区、数据库、日志、证书或 API Key 放进 GitHub、Issue 或 AI 聊天。公开仓库与发行包仅使用虚构样例，不包含运行数据。
